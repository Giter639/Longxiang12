## 快速开始

1. clone 本仓库（**放在纯英文路径**）
2. Android Studio 打开 `FocusDu/`
3. 双击根目录 `启动器.bat` 直接跑 App
4. 每个 PR 由 CI 自动构建 + 47 个单测把关；合并需至少 1 人 Approve + 手动合并
