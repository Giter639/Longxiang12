# R3 光照场景样本（X15）

本目录只提供采样清单和文件命名规则。当前没有拍摄视频，状态为“待现场采样”。

## 目录结构

```text
r3-light-samples/
  sample_manifest.csv
  videos/
    S001.mp4
    ...
    S060.mp4
```

## 采样要求

- 每个场景 10 组，每组至少 30 秒有效画面，其中包含正常姿态和一次低头/偏近。
- 使用同一台目标 OPPO 手机、同一支架位置和同一名受试者完成一组对照。
- 视频保留时间戳和场景标签；不得记录姓名、学校或其他身份信息。
- 光照场景定义：正常、偏暗、逆光、眩光、左右不均、夜间。
- 拍摄后随机抽取 10% 复核场景标签，一致率目标不低于 90%。

## 文件命名

`S<三位编号>_<scene>_<device-model>.mp4`，并在 `sample_manifest.csv` 中填写实际条件、文件数和复核人。
