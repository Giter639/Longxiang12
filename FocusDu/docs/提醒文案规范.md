# 提醒人格与文案规范（T5-01）

## 设计原则

- 每条提醒只描述可观察状态，并给出一个可执行动作。
- 使用“偏近、低头、离屏、光照偏暗”等描述，不做医学判断。
- 不使用“诊断、治疗、病症、近视、颈椎病、压力、焦虑、疲劳度”等表述。
- 不使用羞辱、恐吓或强制锁机措辞。
- 所有提醒都可以延后、静默或关闭。

## 三种人格

| 人格 | 表达方式 | 资源前缀 |
| --- | --- | --- |
| 温和陪伴 | 先照顾感受，再给一个小动作，不命令、不施压 | `_gentle` |
| 教练引导 | 给出明确动作和时长，帮助继续但不过度热情 | `_coach` |
| 简洁严格 | 直接说明状态和动作，不羞辱、不夸张 | `_strict` |

## 场景映射

| 场景 | 规则 |
| --- | --- |
| 距离轻度偏近 | `DISTANCE / LIGHT` |
| 持续近距离 | `DISTANCE / MODERATE` 或 `SEVERE` |
| 低头 | `POSTURE / LIGHT` |
| 持续前倾 | `POSTURE / MODERATE` 或 `SEVERE` |
| 轻度困倦 | `DROWSINESS / LIGHT` |
| 中度困倦 | `DROWSINESS / MODERATE` |
| 重度困倦 | `DROWSINESS / SEVERE` |
| 光照偏暗 | `LIGHT / dark` |
| 逆光 | `LIGHT / backlight` |
| 眩光或光照不均 | `LIGHT / glare` 或 `uneven` |
| 久坐 | `SEDENTARY` |
| 离屏 | `OFF_SCREEN` |

## 36 条文案

| 场景 | 温和陪伴 | 教练引导 | 简洁严格 |
| --- | --- | --- | --- |
| 距离轻度偏近 | 距离有点近，往后坐一点会更舒服。 | 把手机放远一些，回到校准时的位置。 | 距离偏近，请后移。 |
| 持续近距离 | 已经持续近距离用眼，拉远一点，短暂放松再继续。 | 先后移到正常距离，放松片刻，再回到当前任务。 | 持续距离过近，立即后移。 |
| 低头 | 头有点低了，轻轻抬起头来。 | 抬头坐直，让耳朵回到肩膀上方。 | 低头了，请坐直。 |
| 持续前倾 | 身体有些前倾，靠回椅背调整一下。 | 背靠椅背，双肩放松，视线保持在前方。 | 持续前倾，立即坐正。 |
| 轻度困倦 | 眼睛需要缓一缓，看远处几秒再继续。 | 看向远处约 20 秒，再回到任务。 | 远眺 20 秒。 |
| 中度困倦 | 闭眼时间有些长，起来活动一下再继续。 | 离屏走动 1 分钟，回来后重新坐稳。 | 暂停活动，起身 1 分钟。 |
| 重度困倦 | 现在看起来比较困倦，建议停下来休息一会儿。 | 停止当前任务，离屏休息 1–2 分钟再决定是否继续。 | 停止专注，立即休息。 |
| 光照偏暗 | 画面偏暗，开一盏灯会更容易看清。 | 打开台灯，把主光放在书桌和脸部前方。 | 光线偏暗，请开灯。 |
| 逆光 | 背后光线有点强，调整座位或光源会更舒服。 | 避开背后的强光，让光源落在脸部前方。 | 逆光，请调整座位。 |
| 眩光或光照不均 | 画面里有强反光，调整台灯角度或避开直射光。 | 把光源移到侧前方，减少屏幕和人脸反光。 | 眩光或光照不均，请调整灯光。 |
| 久坐 | 已经坐了一阵，起身走动一下会更舒服。 | 离座活动 1–2 分钟，回来后重新调整坐姿。 | 久坐，请立即起身。 |
| 离屏 | 暂时没看到你，计时会继续；回来后我们接着记录。 | 离开屏幕期间计时继续，回到座位后看向镜头。 | 检测到离屏，计时未暂停。 |

## 资源对应

提醒文案已写入 `FocusDu/app/src/main/res/values/strings.xml`：

- `reminder_distance_*`
- `reminder_posture_*`
- `reminder_drowsiness_*`
- `reminder_light_*`
- `reminder_sedentary_*`
- `reminder_off_screen_*`

每种场景包含 `_gentle`、`_coach` 和 `_strict` 三套文案。
