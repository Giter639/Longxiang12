# R3 兼容与降级矩阵（X14）

## 对外承诺

| 范围 | 承诺 |
| --- | --- |
| 所有 CameraX 可运行且满足 minSdk 26 的 OPPO 机型 | 应用可启动，使用统一运行时适配路径；能力不足时降级，不崩溃 |
| 完成本文实测的机型 | 才可宣称达到 8fps、30 分钟稳定等量化指标 |
| 无相机、无权限或未知机型 | 番茄钟、提醒、报告和专注守护配置继续可用 |

## 场景矩阵

每项必须写“通过 / 降级 / 失败 / 待验证”，不得用推断代替实测。

| 场景 | 检查内容 | 预期降级 | 当前结论 |
| --- | --- | --- | --- |
| 正常室内光 | 前摄、640×480、目标 8fps | 切换到设备支持的最接近分辨率 | 待真机 |
| 低光照 | 取流与置信度 | 低置信样本不驱动提醒；界面提示改善光照 | 待真机 |
| 逆光 | 人脸区域过暗/背景过曝 | 不输出 lux；提示逆光，持续低置信时暂停视觉提醒 | 待真机 |
| 眩光/反光 | 局部过曝与关键点丢失 | 暂停风险判定，保留番茄计时 | 待真机 |
| 戴眼镜 | 镜片反光导致关键点低置信 | 不强制提醒；提示重新校准 | 待真机 |
| 无前摄/前摄被占用 | 相机回退与降级 | 自动尝试后摄；仍不可用则切换 `NoCameraStreamer` | 待真机 |
| 使用情况权限拒绝 | P10 拦截能力 | 显示权限未授予，不启动应用轮询 | 自动化逻辑已覆盖，待真机 UI 验证 |
| 悬浮窗权限拒绝 | P10 拦截能力 | 保存限制应用选择，但不弹拦截页 | 自动化逻辑已覆盖，待真机 UI 验证 |
| 通知使用权拒绝 | 专注期间通知摘要 | 摘要为空，不读取正文，不影响番茄钟 | 自动化逻辑已覆盖，待真机验证 |
| 低端机/持续推理不足 | 帧率与温度 | 降低推理频率或分辨率，保持计时和报告 | 待真机 |

## 真机记录字段

| 字段 | 说明 |
| --- | --- |
| 机型 | `Build.MODEL` 与公开销售名称 |
| 系统 | ColorOS 版本、Android API、补丁日期 |
| 相机 | 前/后摄、实际分辨率、实际帧率范围 |
| 性能 | 30 分钟平均/最低帧率、内存、电池温度、电量下降 |
| 视觉异常 | 低光、逆光、眩光、眼镜反光下的提示与暂停行为 |
| 守护 | 前台识别延迟、拦截页触发、二次确认、紧急放行 |
| 结论 | 完全支持 / 通用可用 / 仅安全降级 |
