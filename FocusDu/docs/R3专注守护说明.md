# R3 专注守护说明（T4-01 / T4-03 / T4-05）

## 权限

P01 逐项展示并跳转授权：

| 权限 | 用途 | 未授予时 |
| --- | --- | --- |
| 相机 | P03 坐姿校准与视觉输入 | 保留番茄钟、提醒和报告，视觉功能降级 |
| 通知（Android 13+） | 显示番茄计时前台通知 | 计时仍运行，但系统可能隐藏通知 |
| 使用情况访问 | 判断当前前台应用 | 不触发应用拦截 |
| 通知使用权 | 只记录专注期间通知来源应用 | 休息页显示“未捕获到应用通知” |
| 悬浮窗 | 显示 P10 软拦截页 | 保留应用选择和配置，但不弹出拦截页 |

权限状态分为“已授予 / 未授予 / 已撤回”。撤回状态通过“曾经授予、当前不可用”判断。

## 拦截流程

1. 用户在 P10 选择限制应用；电话、联系人和系统安全类应用不会出现在可选项中。
2. 番茄进入 FOCUS 后，R3 每 250ms 查询一次前台应用。
3. 当前应用命中限制集合，且使用情况和悬浮窗权限齐全时，显示软拦截页。
4. “返回专注”直接回到专注有度；“仍要使用”需要再次点击确认。
5. 用户离开该应用后，本轮放行状态自动清除。

电话、联系人、inCallUI、Telecom、SystemUI、系统设置、紧急与系统安全类包始终放行。

## 通知摘要

- 只记录专注期间通知的来源包名和次数。
- 不读取、存储或展示通知标题、正文、联系人和附件。
- 不取消原通知，也不标记已读；原应用内消息保持未读。
- 摘要只保存在内存，开始下一轮专注时清空，不上传、不写 Room。
- 暂停或离开 FOCUS 后停止采集；休息页可查看本轮应用通知来源汇总。

## 已知边界

- UsageStats 没有实时回调。250ms 轮询是软件侧目标，ColorOS 实际调度与上报延迟必须用真机测量；任务卡 `<300ms` 目前标为待验证。
- 应用自绘 Toast、页面内气泡不属于系统通知，不会被捕获。
- 系统安全通知可能不向通知监听服务暴露，也不应被视为普通消息。
- 悬浮窗与使用情况访问属于敏感权限，应用商店审核时需要明确用途和隐私说明。
