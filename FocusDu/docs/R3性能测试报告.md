## 测试方法

1. 连接真机并安装 Debug 或 Beta APK。
2. 确认 `adb` 可用，执行 `FocusDu/tools/r3_performance_capture.ps1`。
3. 在手机上进入 P03 并开始连续取流，保持屏幕和机位不变。
4. 脚本运行 30 分钟，采集 `R3_PERF` 日志、电池和内存快照。
5. 将输出目录附在测试记录中，不使用未实测数值填写本报告。
