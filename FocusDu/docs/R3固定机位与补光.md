# R3 固定机位、支架与补光方案（X12）

## 目标

用普通手机支架和台灯建立稳定、可复现的固定机位，降低前摄畸变、遮挡和光照变化对识别的影响。

## 推荐摆位

```text
侧面：
       手机前摄
          |
          | 50–70 cm
          v
      眼睛与面部
          |
       桌面/书本

俯视：
       背景
  灯         灯
     \       /
      \     /
       面部
       手机
```

- 手机竖放在桌面前方，前摄大致与眼睛同高，允许低于视线 0–10 cm。
- 手机到脸部建议 50–70 cm；以完整拍摄头部和肩线为准。
- 手机向上仰 5–15°，避免只拍到额头或桌面。
- 屏幕尽量朝用户，但不要用手遮挡前摄。
- 前摄画面必须完整包含脸部；肩线可作为可选辅助，不要求全身入镜。

## 低成本支架

| 场景 | 方案 | 固定方式 |
| --- | --- | --- |
| 书桌 | 桌面手机夹 + 可调臂/书堆 | 底部贴桌，镜头高度固定；书本仅作稳定垫高 |
| 床头 | 床头夹或床边三脚架 | 夹持点避开软床面，镜头朝向坐姿头部 |
| 自习室 | 折叠三脚架 + 手机夹 | 三脚架两脚朝前防倾倒，地面标记位置 |

支架必须稳定，连续 30 分钟不滑动；演示前在桌面或地面用胶带标记支架脚位置。

## 台灯补光

- 主灯放在面部的左前或右前约 45°，略高于眼睛，避免直接照射镜头。
- 不要让强光源位于人物背后形成逆光。
- 避免单一强点光源造成半边脸过曝、另半边过暗。
- 夜间保留背景基础照明，避免只照亮人脸。
- 不使用会频闪的廉价灯；录制时检查画面是否出现明暗条纹。

## 三种场景复现步骤

1. 按示意图放置支架，在桌面标记支架脚和手机边缘位置。
2. 打开 P03，确认脸部和肩线完整进入画面。
3. 调整台灯到面部左前方 45°，检查背景不过曝、人脸不偏暗。
4. 完成一次校准，记录手机型号、保存摆位照片。
5. 后续测试不得改变支架、灯光和座椅位置。

## 验收

需要 3 名队员在书桌、床头、自习室各完成一次摆位；其中至少 2 人无需他人调整即可一次摆对。当前没有现场照片和实测记录，状态为“待验证”。
