# R3 演示环境搭建（X13）

## 设备清单

- 一台目标 OPPO 手机，安装最终签名 APK。
- 一个稳定支架和防滑垫。
- 两盏可调亮度台灯，分别用于面部主光与背景补光。
- 备用手机或相机用于第二机位拍摄。
- 充电器、数据线、移动电源和离线演示视频。
- 桌面定位胶带、卷尺和场景检查表。

## 环境布置

1. 固定演示桌，不把手机放在柔软、易移动的物体上。
2. 按 `R3固定机位与补光.md` 标记支架、座椅和台灯位置。
3. 主光位于面部左前 45°，背景补光避免形成逆光和眩光。
4. 第二机位同时拍摄手机屏幕、用户姿态和环境，确保功能与真实操作一致。
5. 演示电脑开启飞行模式或关闭无关通知，现场 Wi-Fi 只保留必要连接。

## 彩排流程

1. 冷启动应用并检查全部权限状态。
2. 完成固定机位确认和个人基线校准。
3. 开始番茄钟，演示正常状态与持续低头/偏近提醒。
4. 打开一个限制应用，确认软拦截和二次确认退出。
5. 制造一次非紧急通知，休息页只显示来源应用，原应用消息保持未读。
6. 完成休息与报告，确认报告生成和前后对比。
7. 拔网或关闭网络，重复离线流程。

## 完成标准

- 连续彩排两次，期间不移动支架、灯光、座椅和机位。
- 两次彩排 5 条主路径均通过，无崩溃和阻断级缺陷。
- 所有演示数据真实；模拟数据必须在屏幕和讲稿中明确标注。
- 当前仅完成方案文档，真机、双机位拍摄和两次彩排为“待现场完成”。
